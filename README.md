# Task 4 – Cross-Browser Testing with BrowserStack

# Objective
The goal of this task was to run **automated tests** across multiple browsers and devices using **BrowserStack’s Selenium Grid** to ensure compatibility of a login form.

# Approach
1. Integrated Selenium test scripts with **BrowserStack Cloud Grid**.  
2. Executed test cases on multiple browsers: **Chrome, Firefox, Safari, Edge**.  
3. Verified login functionality consistency across different operating systems (Windows, macOS).  
4. Documented issues and discrepancies.  

# Test Scenarios
-  Login works correctly across all tested browsers.  
-  Slight UI alignment issue in Safari mobile view.  
-  Slower load times detected on Edge.  

# Tools & Technologies Used
- Selenium (Python)  
- BrowserStack Cloud Grid  
- PyTest / Unittest Framework  

# Outcome
- Ensured cross-browser compatibility.  
- Documented browser-specific issues for debugging.  
- Improved test coverage by running on multiple environments.
